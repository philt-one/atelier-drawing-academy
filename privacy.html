About Atelier

Atelier Drawing Academy is a free, skills-only plugin that provides drawing lessons, exercises, and feedback within ChatGPT. The plugin does not operate a separate application server, database, analytics service, or external service that receives users' drawing photographs or conversations.

Information you share in ChatGPT

When you use Atelier, you may provide prompts, lesson preferences, progress checkpoints, and photographs of drawings to ChatGPT. They are processed within ChatGPT under the applicable OpenAI terms, privacy notices, and settings. The Atelier publisher does not receive a separate copy of those chats or uploads through the plugin, and does not independently store them.

Atelier may generate progress summaries inside a conversation. It does not maintain its own persistent learner profiles or guarantee that progress is available in other chats.

Website hosting

This informational website is hosted using GitHub Pages. GitHub may process technical data needed to deliver the site, such as IP addresses and request information, according to its own privacy practices. The publisher has not added custom website analytics, advertising trackers, or tracking cookies.

Support through GitHub Issues

If you open a GitHub Issue for support, the issue and information you choose to post may be publicly visible and processed by GitHub according to GitHub's own policies. Do not publish private conversations, personal data, or sensitive drawings in issues. You can edit or delete your GitHub submissions using the controls GitHub makes available, subject to GitHub's policies and retained records.

Data sharing and retention

Atelier itself does not transfer chat content or user drawing uploads to a publisher-operated database, third-party drawing analysis service, or mailing list. Retention and deletion of ChatGPT conversations are controlled by the applicable OpenAI service and user settings. GitHub determines its own handling of website requests and GitHub Issues.

Privacy questions

For privacy inquiries or requests concerning Atelier Drawing Academy, contact atelier.gpt.support@gmail.com. This is a publisher contact address; do not use public GitHub Issues for confidential privacy requests. Emails sent to this address are handled through the email provider and may be retained as correspondence for responding to requests. OpenAI and GitHub control their own services and their own data request processes.
