How can we help?

Atelier Drawing Academy is a free drawing-tutor plugin. For plugin problems, feedback, accessibility issues, or feature requests, please open an issue in our public GitHub repository.

Open a support request on GitHub ↗

You need a GitHub account to submit an issue. Issues are public, so do not include personal details, private conversations, unpublished drawings, or sensitive photographs. Response times are not guaranteed.

Common questions

How do I get feedback on a drawing?
Upload your drawing within your Atelier conversation and request a critique. Do not post private drawings to GitHub Issues.

Will Atelier remember my progress?
Progress can be summarized in portable checkpoints. Persistent cross-conversation storage is not guaranteed.

Does it cost anything?
Atelier has no in-plugin purchases, paid lessons, or subscriptions. ChatGPT access may be subject to platform terms or plan limits.
